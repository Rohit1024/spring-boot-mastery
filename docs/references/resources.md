# Spring Boot & Enterprise Systems Resources

## Knowledge

- [Spring Framework Official Documentation](https://docs.spring.io/spring-framework/reference/)
  The authoritative reference for Core IoC, AOP, Bean lifecycle, and Spring MVC.
- [Spring Boot Official Reference Guide](https://docs.spring.io/spring-boot/reference/)
  Covers Auto-Configuration, Actuator, Profiles, DevTools, and Starters.
- [Jakarta Bean Validation Specification](https://jakarta.ee/specifications/bean-validation/3.0/)
  Standard for constraint annotations, validation groups, and custom validators.
- [MapStruct Reference Guide](https://mapstruct.org/documentation/stable/reference/html/)
  High-performance, compile-time type-safe Java bean mapping framework.
- [Spring Security Reference Manual](https://docs.spring.io/spring-security/reference/)
  Covers Security Filter Chains, OAuth2, JWT, Session Management, and Method Security in Spring 6.
- [Spring AI Documentation](https://docs.spring.io/spring-ai/reference/)
  Guides for Models, ChatClients, Prompt engineering, Vector Stores, RAG, and MCP tool servers.
- [Project Reactor Core Documentation](https://projectreactor.io/docs/core/release/reference/)
  The foundational reference for reactive streams, Mono, Flux, backpressure, and operators.
- [Enterprise Integration Patterns — Gregor Hohpe & Bobby Woolf](https://www.enterpriseintegrationpatterns.com/)
  The definitive catalog of messaging patterns (Pub/Sub, Outbox, SAGA, Idempotency, Dead Letter Channel).
- [Designing Data-Intensive Applications — Martin Kleppmann](https://dataintensive.net/)
  Essential text for distributed systems, CAP theorem, replication, partitions, transactions, and eventual consistency.
- [Kafka: The Definitive Guide — Gwen Shapira et al.](https://www.oreilly.com/library/view/kafka-the-definitive/9781492043072/)
  Primary source for Kafka architecture, partitions, consumer groups, offset management, and delivery guarantees.
- [Kubernetes Official Documentation](https://kubernetes.io/docs/)
  Core reference for Pods, Deployments, Services, Ingress, and cluster orchestration.

## Wisdom (Communities)

- [r/java](https://reddit.com/r/java) & [r/SpringBoot](https://reddit.com/r/SpringBoot)
  High-signal discussions on JVM practices, Spring updates, and modern Java backend design.
- [Spring Community Slack / Gitter](https://spring.io/community)
  Direct engagement with Spring engineers and ecosystem contributors.
- [GitHub Spring Boot Discussions & Issues](https://github.com/spring-projects/spring-boot/discussions)
  For investigating internal framework behavior, bug reports, and architectural decisions.
