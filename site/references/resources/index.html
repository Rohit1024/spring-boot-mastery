Spring Boot & Enterprise Systems Resources¶

Knowledge¶

  • Spring Framework Official Documentation The authoritative reference for Core IoC, AOP, Bean lifecycle, and Spring MVC.
  • Spring Boot Official Reference Guide Covers Auto-Configuration, Actuator, Profiles, DevTools, and Starters.
  • Jakarta Bean Validation Specification Standard for constraint annotations, validation groups, and custom validators.
  • Jakarta Persistence Specification 3.1 Official standard for Entity lifecycle, EntityManager, PersistenceContext, and JPQL.
  • Hibernate ORM User Guide Authoritative manual for dirty checking, ActionQueue, fetching strategies, Envers, and caching.
  • High-Performance Java Persistence — Vlad Mihalcea The definitive industry handbook on optimizing JPA, Hibernate, batching, caching, and connection pooling.
  • Spring Data JPA Reference Documentation Covers repository interfaces, derived queries, entity graphs, and auditing.
  • MapStruct Reference Guide High-performance, compile-time type-safe Java bean mapping framework.
  • SpringDoc OpenAPI 3 Documentation Interactive API documentation generation, Swagger UI, and OpenAPI 3 spec builder for Spring Boot 3.
  • Micrometer Application Observability Guide Dimensional metrics facade for Prometheus, Datadog, InfluxDB, and New Relic.

  • Logstash Logback Encoder Guide Structured JSON log formatting for SLF4J, Logback, and ELK stack integration.

  • Spring Security Reference Manual Covers Security Filter Chains, OAuth2, JWT, Session Management, and Method Security in Spring 6.

  • Spring AI Documentation Guides for Models, ChatClients, Prompt engineering, Vector Stores, RAG, and MCP tool servers.
  • Project Reactor Core Documentation The foundational reference for reactive streams, Mono, Flux, backpressure, and operators.
  • Enterprise Integration Patterns — Gregor Hohpe & Bobby Woolf The definitive catalog of messaging patterns (Pub/Sub, Outbox, SAGA, Idempotency, Dead Letter Channel).
  • Designing Data-Intensive Applications — Martin Kleppmann Essential text for distributed systems, CAP theorem, replication, partitions, transactions, and eventual consistency.
  • Kafka: The Definitive Guide — Gwen Shapira et al. Primary source for Kafka architecture, partitions, consumer groups, offset management, and delivery guarantees.
  • Kubernetes Official Documentation Core reference for Pods, Deployments, Services, Ingress, and cluster orchestration.

Wisdom (Communities)¶

  • r/java & r/SpringBoot High-signal discussions on JVM practices, Spring updates, and modern Java backend design.
  • Spring Community Slack / Gitter Direct engagement with Spring engineers and ecosystem contributors.
  • GitHub Spring Boot Discussions & Issues For investigating internal framework behavior, bug reports, and architectural decisions.
