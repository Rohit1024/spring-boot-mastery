# Module 3: Persistence Mastery — Hibernate, JPA & R2DBC Completed

Completed Module 3 mastering relational data persistence, ORM internals, transaction management, multi-database architecture, and auditing in Spring Boot 3.x.

## Key Competencies Acquired
- **JDBC vs Hibernate ORM Internals**: Understood the Object-Relational Impedance Mismatch, `EntityManagerFactory` / `EntityManager` lifecycle, the 4 Entity States (`TRANSIENT`, `MANAGED`, `DETACHED`, `REMOVED`), the Persistence Context (First-Level Cache), and automatic Dirty Checking via internal snapshot comparison during flush.
- **Spring Data JPA & Query Abstractions**: Mastered the repository hierarchy (`Repository` -> `CrudRepository` -> `JpaRepository`), dynamic repository proxy generation, derived query method keyword parsing, JPQL vs Native SQL trade-offs, and `Page<T>` vs `Slice<T>` performance differences (eliminating `COUNT(*)` overhead for infinite scrolling).
- **Entity Relationships & The N+1 Problem**: Configured bidirectional associations (`@OneToOne`, `@ManyToOne`, `@OneToMany`, `@ManyToMany`), relationship ownership with `mappedBy`, defensive synchronization methods, cascade options vs `orphanRemoval`, and eliminated N+1 query storms using JPQL `JOIN FETCH`, `@EntityGraph`, `@BatchSize`, and record DTO constructor projections.
- **Transaction Management & `@Transactional`**: Dissected Spring AOP transaction proxy interception (`TransactionInterceptor`, `PlatformTransactionManager`), the Self-Invocation proxy bypass trap, checked vs unchecked rollback rules (`rollbackFor`), propagation levels (`REQUIRED`, `REQUIRES_NEW`, `NESTED`), and database isolation levels (`READ_COMMITTED`, `REPEATABLE_READ`, `SERIALIZABLE`) against concurrency anomalies.
- **Multi-DataSource & Polyglot Persistence**: Configured multiple independent relational `DataSource` instances (PostgreSQL primary + MySQL secondary) with custom `LocalContainerEntityManagerFactoryBean` and `JpaTransactionManager` beans, dynamic Read/Write replica routing via `AbstractRoutingDataSource`, and coexisting Spring Data MongoDB document repositories.
- **Entity Auditing & Historical Tracking**: Implemented automated audit timestamps (`@CreatedDate`, `@LastModifiedDate`, `@CreatedBy`, `@LastModifiedBy`) with `AuditorAware<String>` wired to the Spring Security context, full historical revision tracking with Hibernate Envers (`@Audited`, shadow `_AUD` tables, `AuditReader`), and modern soft deletes with `@SQLDelete` and `@SQLRestriction`.
