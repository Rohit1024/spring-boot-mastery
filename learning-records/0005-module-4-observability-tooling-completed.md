# Module 4: Observability, Tooling & API Docs Completed

Completed Module 4 mastering developer tooling, production monitoring, metrics instrumentation, interactive API documentation, and distributed structured logging in Spring Boot 3.x.

## Key Competencies Acquired
- **Spring Boot DevTools & Fast Inner Loops**: Understood the Two-ClassLoader architecture (Base ClassLoader vs Restart ClassLoader), sub-500ms application restarts, automatic development property overrides (disabling template caches, auto-enabling H2 web console), and embedded WebSocket LiveReload for instant browser refresh.
- **Production Health & Actuator Observability**: Configured `spring-boot-starter-actuator`, Kubernetes Liveness (`/actuator/health/liveness`) and Readiness (`/actuator/health/readiness`) probes, custom `HealthIndicator` beans for external third-party dependencies, and hardened sensitive management endpoints using Spring Security.
- **Micrometer Metrics & Prometheus**: Instrumented custom business metrics using `MeterRegistry` (`Counter`, `Timer` with `publishPercentiles` for p50/p95/p99 latency SLAs, `Gauge`), and exposed dimensional metrics for Prometheus scraping via `/actuator/prometheus`.
- **OpenAPI 3 & Swagger UI**: Integrated `springdoc-openapi-starter-webmvc-ui` for automated, live API contract generation, documented endpoints and request/response payloads using `@OpenAPIDefinition`, `@Operation`, `@ApiResponses`, `@Schema`, and `@Parameter`, configured JWT Bearer token security schemes (`@SecurityScheme`, `@SecurityRequirement`), and segmented documentation via `GroupedOpenApi`.
- **Structured JSON Logging & MDC Correlation**: Configured Logback with `logstash-logback-encoder` to emit structured JSON logs, implemented a high-precedence `OncePerRequestFilter` to populate and sanitize SLF4J `MappedDiagnosticContext` (MDC) with `traceId` and `clientIp`, prevented ThreadLocal cross-tenant leaks with mandatory `try-finally` blocks, and executed runtime log level adjustments via `/actuator/loggers`.
- **Centralized Log Aggregation with ELK Stack**: Architected an end-to-end log shipping pipeline streaming JSON logs over non-blocking TCP sockets (`LogstashTcpSocketAppender`) to Logstash, indexed time-series logs in Elasticsearch, provisioned local observability stacks using Docker Compose, and executed multi-service trace queries using Kibana Query Language (KQL).
