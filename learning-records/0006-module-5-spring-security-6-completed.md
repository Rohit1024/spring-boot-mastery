# Module 5: Spring Security 6, OAuth2 & Identity Completed

Completed Module 5 mastering enterprise security architecture, filter chain delegation, cryptographic password hashing, stateless JWT authentication, fine-grained RBAC with method security, and Google OAuth2/OIDC integration in Spring Boot 3.x.

## Key Competencies Acquired
- **Spring Security 6 Architecture & Filter Chains**: Understood how Tomcat's servlet container bridges to Spring's IoC container via `DelegatingFilterProxy` and `FilterChainProxy` (`springSecurityFilterChain`). Mastered modern component-based security using `SecurityFilterChain` bean declarations, lambda DSLs, and `SecurityContextHolder` lifecycle across thread boundaries.
- **Cryptographic Password Hashing & Session Management**: Mastered adaptive, memory-hard hashing algorithms (**Argon2id** and **BCrypt**) over vulnerable fast hashes (MD5/SHA-256). Configured `DelegatingPasswordEncoder` for zero-downtime prefix-based upgrades (`{argon2}`, `{bcrypt}`). Implemented stateful session protections, including session fixation mitigation (`migrateSession()`) and concurrent session caps (`maximumSessions(1)`).
- **Stateless Authentication with JWT**: Dissected RFC 7519 JSON Web Token anatomy (Header, Claims, Signature). Built a production-grade `JwtAuthenticationFilter` extending `OncePerRequestFilter` with JJWT 0.12+, populated `UsernamePasswordAuthenticationToken` into `SecurityContextHolder`, and implemented Access Token + Refresh Token rotation with Redis revocation.
- **Role-Based & Permission-Based Access Control (RBAC)**: Mastered coarse roles (`ROLE_ADMIN`) vs fine-grained authorities (`order:write`), configured `@EnableMethodSecurity`, and enforced domain-level authorization via `@PreAuthorize`, `@PostAuthorize`, and custom SpEL security beans (`@orderSecurity.isOwner()`).
- **Google OAuth2 & OpenID Connect (OIDC)**: Mastered the OAuth 2.0 Authorization Code Flow with PKCE, configured `spring-boot-starter-oauth2-client` for Google IdP, implemented a custom `OAuth2UserService` to auto-provision and sync user records in PostgreSQL, and bridged social logins to stateless SPA/mobile clients via a custom JWT `AuthenticationSuccessHandler`.
- **Diagnostics & Troubleshooting**: Diagnosed and resolved upstream JWT filter exceptions by delegating to Spring MVC's `HandlerExceptionResolver`, eliminated silent `403 Forbidden` authorization denials caused by `ROLE_` prefix mismatches, and resolved CORS preflight `OPTIONS` blocks in `SecurityFilterChain`.
